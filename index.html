SafeEnv: Terminal-Based Cryptographic Environment Manager

safeEnv is a professional, zero-trust CLI tool designed to protect, manage, and securely distribute sensitive configuration environment files across development teams. By combining hardened local key derivation with modern Curve25519 asymmetric envelope encapsulation, safeEnv ensures secrets remain completely encrypted at rest on central remote servers while allowing instant local decryption and provisioning directly via the terminal.

Installation & Setup

Follow the steps below to set up Go and compile the latest binary snapshot tracking target tool directly into your system cluster profile runtime architecture.

1. Install Go (Golang)

Ensure Go version 1.21 or higher is deployed globally on your machine workspace environment framework:

macOS (Homebrew)

brew install go

Ubuntu/Linux (apt)

sudo apt update
sudo apt install golang-go

⚠️ Important Step: Ensure your Go binary path ($GOPATH/bin or $HOME/go/bin) is added to your system's PATH environment variable so your shell can discover compiled global packages cleanly.

2. Fetch and Build safeEnv

Compile and lock the isolated binary bundle parameters directly down from the repository distribution server:

go install github.com/Oladev-01/safeenv/cmd/safeenv@v0.1.8

Technical Architecture Overview

safeEnv completely decouples application security contexts from backend structures using a zero-trust design:

  • Master Key Derivation (Argon2id): When managing internal asymmetric private keys locally, a master passphrase is encrypted and verified using a highly robust Argon2id configuration algorithm. This implementation prevents offline high-performance GPU array brute-force optimizations.
  • Asymmetric Envelope Encryption (X25519 / Curve25519): Rather than re-encrypting massive configuration payloads independently for each developer, safeEnv abstracts access control. The file payload is securely wrapped exactly once using a highly volatile random symmetric team key. This unique access key is then packed inside separate authenticated cryptographic distribution envelopes (box.SealAnonymous) customized directly for each explicit user's public identity.
  • Authenticated Symmetric Storage (AES-256-GCM): The binary payload representing the configuration safe is locked via a high-performance, hardware-accelerated block cipher mode. Integrated validation tags guarantee instantaneous detection of data tampering, preventing invalid payload delivery pipelines.

Command Reference

The system organizes functional context logic loops under explicit execution namespaces:

safeenv init

Configures connection parameters linking the terminal instance with your underlying Supabase persistence layer.

safeenv init

Interactive Inputs Required:

  • Supabase Project URL (e.g., https://xyz.supabase.co)
  • Supabase Service Role Key (Administrative credentials)

safeenv register

Provisions an isolated cryptographic user identity onto the local hardware cluster and syncs public metadata profiles to the network.

safeenv register

Security Context: If an active terminal signature token is currently registered on the host environment, the runtime stops processing immediately and guides the engineer toward running safeenv reset to prevent identity corruption.

safeenv team create

Establishes a new secure corporate or engineering department workspace environment, automatically designating the calling user as the infrastructure Admin.

safeenv team create --team <team_name> --user <your_username>

Required Flags:

  • -t, --team : A completely unique target tracking name for your team structure namespace.
  • -u, --user : Your explicit, distinct profile identifier string inside this specific team pool.

safeenv team join

Accepts a verified invitation ticket block to enroll your active cryptographic public key credentials inside a collaborative team pool.

safeenv team join --team <team_name> --user <your_username> --code <6_digit_code>

safeenv team invite

Generates an ephemeral, secure transactional access token allowing external engineers to attach their accounts to a team signature map.

safeenv team invite --team <team_name>

Output Constraints: Outputs a copy-pasteable 6-digit verification code with an absolute chronological expiration hard-limit set to exactly 1 hour from creation.

safeenv safe push

Encrypts, isolates, and builds distribution vaults for a cleartext environment configuration file, synchronizing storage components immediately to the persistence database.

# Distribute to everyone within the team workspace context
safeenv safe push .env --team your-team --all

# Target specific tracking identities with custom signature filenames
safeenv safe push production.json -t your-team -u user1 -u user2 -n custom-filename

safeenv safe pull

Retrieves, verifies, and extracts an encrypted distribution safe vault down to your active physical terminal storage path.

# Pull down latest data values dynamically
safeenv safe pull production.env --team your-team --output .env

# Pull down historical version configuration target matrix nodes
safeenv safe pull production.env -t your-team --version 3 -o decrypted.json
